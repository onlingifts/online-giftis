| صور الكتالوج التركي في خرائط المنتجات لا تضع الصورة التركية أولاً | استخدام الصورة التركية الفعلية وإدراج الصفحات التركية في خريطة الصور |
| صفحة تسويق عامة في sitemap بلا canonical | إخراج `marketer.html` من خريطة صفحات المتجر؛ الصفحة نفسها لم تُحذف |
| فشل تنزيل صورة مؤقتاً يؤدي لحذف النسخة السابقة | الاحتفاظ بآخر نسخة محفوظة عند فشل التنزيل |
| بيانات النشاط لا تتضمن العنوان المتحقق منه | إضافة العنوان والهاتف ورابط Google Maps إلى بيانات OnlineStore؛ اسم المالك الشخصي لم يضف |

## الملفات المعدلة

- `products/index.html` والملف الجديد `tr/products/index.html`: HTML أولي، روابط اللغات والبيانات الوصفية، اختيار اللغة الصريح فقط؛ وظائف التجارة بقيت كما هي.
- `index.html` و`tr/index.html`: معلومات النشاط المتحقق منها في Schema.
- `scripts/catalog-seo.mjs` جديد: توليد الكتالوج التركي والمحتوى القابل للقراءة بدون JavaScript من بيانات المنتجات الفعلية.
- `scripts/generate-product-pages.mjs` و`scripts/seo-localization.mjs`: توليد المنتج واللغة وBreadcrumbList وخرائط الموقع وصيانة الصور.
- `assets/product-page.js`: تحديث بيانات المنتج المنظمة والبيانات الوصفية.
- 54 ملف `products/<id>/index.html` و37 ملف `tr/products/<id>/index.html`: مخرجات مولدة من API المباشر.
- `sitemap.xml` و`image-sitemap.xml`: 121 صفحة canonical، و91 صفحة منتجات في خريطة الصور.
- `scripts/check-technical-seo.mjs` و`scripts/check-catalog-seo-browser.cjs`: تحقق شامل من الخرائط واللغات والكتالوج الأولي والأسعار.
- `scripts/check-search-browser.cjs` و`scripts/check-boutique-browser.cjs` و`scripts/check-themes-browser.cjs`: توقع مسار الكتالوج التركي الجديد بدلاً من معامل اللغة بعد فتح السلة.
- `.github/workflows/generate-product-pages.yml` و`.github/workflows/check-themes.yml`: استمرار التوليد والفحوص تلقائياً.

## نتائج الاختبار قبل النشر

- 31 اختبار Node ناجح، تشمل المصادقة والفئات والبانرات وتخطيط الرئيسية وSEO وMerchant feeds.
- مطابقة أسعار وعملات ومخزون 91 صفحة منتجات مع لقطة API عامة حديثة (54 منتجاً، 37 ترجمة تركية مكتملة).
- فحص كل صفحات sitemap: موجودة محلياً، indexable، canonical واحد صحيح، JSON-LD صالح، hreflang متبادل، لا عناوين أو أوصاف مكررة بين صفحات الخريطة.
- تحليل ملفي XML وفحص الروابط الداخلية بالصفحات المدرجة.
- فحص 30 عرضاً متجاوباً بعروض 320 و360 و390 و430 و768 و1440 نجح، وكذلك البحث التركي وتفاصيل المنتج وحساب الطلب واختفاء المنتجات المحذوفة في اختبار معزول.
- فحص الكتالوج بدون JavaScript: 54 بطاقة عربية و37 بطاقة تركية وروابط منتجات فعلية.
- متصفح Chromium بعرض 390 و1440: لغة المسار رغم لغة مخزنة معاكسة، مسار اللغة القديم، حفظ معاملات التصفية، تبديل اللغة، عدم التمرير الأفقي.
- اختبارات التجارة المعزولة: معرض الصور، المفضلة، كمية ومخزون، السلة، مراحل الطلب، الحقول المطلوبة، إشعار التحويل، طلب واحد فقط، وتسجيل دخول وخروج تجريبي. لم تُرسل طلبات شراء إلى الإنتاج.
- فحص السمات وبنية JavaScript وJSON-LD والموقع ناجح. إعادة توليد الكتالوج مرتين أعطت المخرجات نفسها.

## حدود واحتياجات متبقية

- الاستضافة الحالية GitHub Pages: معاملات الاستعلام لا تغير استجابة HTML من الخادم. `/products/?lang=tr` يعرض التركية مع JavaScript ويستقر عنوان العرض على `/tr/products/`؛ تعطيل JavaScript على الرابط القديم يبقي HTML العربي. الرابط التركي الأصلي الجديد يعمل بالتركية حتى دون JavaScript. الحصول على تحويل HTTP حقيقي للرابط القديم يحتاج طبقة خادم/استضافة تدعم ذلك؛ لم نغيّر الاستضافة.
- 17 منتجاً لا تملك ترجمة تركية مكتملة. لم تُنشأ لها صفحات تركية مفهرسة أو hreflang تركي مضلل. قد يعرضها الكتالوج التفاعلي الحالي باسمها المتاح، كما كان سابقاً.
- توجد منتجات متشابهة الأسماء/الوصف في مصدر الكتالوج. تمييز metadata بأكوادها لا يستبدل مراجعة المحتوى الأصلي أو توضيح اختلافاتها الفعلية.
- لم يُعثر على صفحة خصوصية مستقلة. صياغة سياسة تصف جمع البيانات ومزوّدي الخدمة ومدد الاحتفاظ تحتاج مراجعة بيانات التشغيل؛ لم تُخترع سياسة أو تُنشر معلومات قانونية غير مثبتة.
- لم تتوفر جلسة موثقة لـGoogle Search Console؛ لا ادعاء عن عدد الصفحات المفهرسة أو تحسن الترتيب. إرسال sitemap وفحص فهرسة الروابط يحتاج وصول الحساب.
- robots.txt يسمح لـGooglebot وbingbot عبر المجموعة العامة، ولـOAI-SearchBot صراحةً. السماح لا يضمن الفهرسة أو الترشيح؛ GPTBot للتدريب لم يُغيّر.
- تاريخ 11 يناير 2016 مأخوذ من تصريح المالك ومتطلبات هذه المهمة، وليس نتيجة تحقق مستقل من سجل تجاري. لا نشر لاسم المالك الشخصي.
- لا aggregateRating أو مراجعات مصطنعة في Schema؛ لم نضف متوسط تقييمات غوغل إلى Product.
- النسخ الثابتة تعكس وقت التوليد، والتحديث المجدول يعمل كل خمس دقائق حسب جدولة GitHub؛ قد يتأخر تشغيله. الأسعار التفاعلية تتحدث من API؛ لا ضمان للتزامن اللحظي لروبوت بلا JavaScript.

## النشر والتحقق الفعلي

- دُمج [PR #58](https://github.com/onlingifts/online-giftis/pull/58) بعد نجاح [فحوص GitHub Actions](https://github.com/onlingifts/online-giftis/actions/runs/38832848418). التزام الدمج `e32b70bef2211501c6ad0a3b92a445dfd7f1928e`.
- نجح [نشر GitHub Pages](https://github.com/onlingifts/online-giftis/actions/runs/38833189242) و[التوليد الآلي بعد الدمج](https://github.com/onlingifts/online-giftis/actions/runs/38833189575).
- فحص HTTP مباشر لجميع روابط sitemap البالغ عددها **121**: كلها **HTTP 200** وكل canonical يطابق الرابط الأصلي. استخدمت معاملات تحقق لتجنب نسخة cache قديمة؛ ليست هذه بيانات فهرسة من Google.
- تحقق مباشر من `/products/` و`/tr/products/`: العربية والتركية في HTML الأولي، 54 و37 بطاقة على الترتيب. تحقق من المنتج 112 باللغتين: canonical صحيح وBreadcrumbList موجودة. robots وخريطتا XML كلها HTTP 200 وتُحلّل دون خطأ.
- [Schema Markup Validator للمنتج 112](https://validator.schema.org/#url=https%3A%2F%2Fonlinegiftis.com%2Fproducts%2F112%2F) عبر Fetch URL للنسخة المنشورة: **0 أخطاء، 0 تحذيرات**؛ كشف Product وBreadcrumbList وCreativeWork. هذه نتيجة عينة واحدة، وليست شهادة لكل صفحات المتجر. [سجل جلسة الفحص](https://agent.tinyfish.ai/runs/0561d6a3-f17d-4f51-8c3e-ce010c4f6559).
- Google Rich Results Test: جرت محاولة CODE للمنتج العربي ومحاولة URL للمنتج التركي المنشور. في المرتين ظهر «Something went wrong — Log in and try again». لم تُرجع البيئة نتيجة فحص أو أهلية أو كشف أخطاء. لذلك هذا البند **غير مكتمل**، ولا يمكن اعتبار نجاح Schema Markup Validator بديلاً عن نجاح Rich Results Test. [جلسة محاولة الرابط](https://agent.tinyfish.ai/runs/881d7264-792c-4a73-acec-b0a276a908b2).
- محاولة Schema بالكود أولاً تعثرت بإدخال النص، ثم نجحت المحاولة بالرابط المنشور كما هو موضح أعلاه. لا تُعد التخمينات التي صدرت أثناء المحاولة المتعثرة أخطاء مكتشفة.
- فحص HTTP باستخدام ترويسات User-Agent بأسماء Googlebot وbingbot وOAI-SearchBot على الرئيسية وrobots والكتالوجين والمنتج 112: نجحت الطلبات الخمسة عشر برمز 200. هذا اختبار بأسماء الزواحف، وليس اتصالاً من عناوين IP الأصلية لتلك الشركات ولا إثبات فهرسة.
- الأداء: جرى الحفاظ على تحسينات الصور المتجاوبة الموجودة، وlazy loading لصور بطاقات HTML وdecoding غير المتزامن، دون تعديل التصميم. لم تُجرَ قياسات Core Web Vitals أو Lighthouse من مستخدمين فعليين، فلا يوجد ادعاء رقمي بتحسن السرعة.

## ما يحتاج متابعة من المالك

1. إكمال Rich Results Test ضمن جلسة تسمح بتشغيله، ثم مراجعة التحذيرات الفعلية إن وجدت.
2. توفير وصول Search Console لمراجعة التغطية والفهرسة وإرسال sitemap وفحص عينة الروابط.
3. استكمال بيانات الترجمة لـ17 منتجاً ومراجعة المنتجات ذات المحتوى المتشابه من المصدر.
4. تأكيد ممارسات الخصوصية الفعلية لصياغة سياسة مستقلة، دون نشر اسم المالك الشخصي ضمن هذا العمل.
5. إذا لزم تحويل HTTP من `/products/?lang=tr` إلى `/tr/products/` قبل JavaScript، يلزم تغيير منفصل في طبقة الاستضافة.

لا تتضمن النتائج ادعاء فهرسة شاملة أو تصدّر نتائج البحث أو ضمان ترشيح ChatGPT.
