## ما لم نعتبره محلولاً

1. **ترويسات HTTP الكاملة:** HSTS وX-Content-Type-Options وframe-ancestors/X-Frame-Options تحتاج طبقة استضافة/Proxy يمكن ضبط ترويساتها. النشر الحالي GitHub Pages؛ لم نغيّر DNS أو الاستضافة. CSP ضمن meta لا يصلح بديلاً عن frame-ancestors.
2. **منع كلمات المرور المسربة:** ما زال Supabase advisors يعرض `auth_leaked_password_protection`. الأدوات المتاحة لا تتضمن تعديل إعدادات Auth. يلزم تفعيلها من إعدادات المشروع، مع التحقق من متطلبات الخطة. المصدر: https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection
3. **تسليم بريد الاستعادة فعلياً:** اختُبر مسار التطبيق باستجابات محاكاة، ولم تُرسل رسائل إلى زبائن. يلزم اختبار رسالة على بريد يملكه المتجر للتأكد من إعدادات المرسل وقائمة روابط إعادة التوجيه وتسليم البريد.
4. **ملاحظات قاعدة البيانات غير الخاصة بالمتجر:** بقي مفتاح خارجي في `nfc_v2.customers.theme_style`، وجدولا backup/staging بلا primary key، و13 حالة RLS بلا policies تمنع الوصول افتراضياً. لم تُمنح صلاحيات جديدة لإخفاء الملاحظات. الفهارس الجديدة قد تظهر مؤقتاً ضمن unused_index حتى تستعملها الاستعلامات؛ لم نحذف الفهارس.
5. **مقاييس البحث:** لم يتوفر وصول Google Search Console أو بيانات ترتيب/زيارات. لا يوجد ادعاء بتحسن الترتيب أو الفهرسة الكاملة أو ضمان اقتراح المتجر دائماً بواسطة محركات الذكاء الاصطناعي.
6. **تباين السعر القديم:** يظهر فحص الوصول تبايناً 4.09:1 للنص الرمادي المشطوب مقابل 4.5:1 المستهدف. لم نغيّر لون هذا النص التزاماً بمنع تغيير ألوان التصميم؛ توسيع مساحة لمس نقاط السلايدر لا يغير لونها أو شكل النقطة.
7. **تفاصيل العطور:** الأوصاف المضافة لا تحل محل توثيق التركيز والحجم والأصالة والمكونات. يجب إدخال المعلومات الحقيقية من الإدارة عند توفرها.
